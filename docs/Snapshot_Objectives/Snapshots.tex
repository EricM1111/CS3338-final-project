\section{Snapshot 1 -- Start}

The purpose of this project is to develop a software system capable of detecting
copy-move forgery in biomedical and scientific images. Copy-move forgery occurs when
a section of an image is duplicated and pasted elsewhere within the same image in
order to manipulate scientific results.

The system will allow users to upload biomedical images through a web interface. The
uploaded image will then be analyzed by a backend detection system that identifies
potentially duplicated regions. The project is intended to help improve scientific integrity
by assisting researchers, reviewers, and institutions in identifying manipulated figures.

This project will be developed incrementally throughout multiple project snapshots.

\section{Snapshot 3 -- Checkpoint 2}

The purpose of Snapshot 3 is to expand the Scientific Forgery Image Detection System
by introducing image analysis functionality capable of identifying potentially fraudulent
regions within uploaded images.

This snapshot focuses on implementing the detection logic that analyzes uploaded
images and identifies areas that may contain copy move forgery.

\subsection{Objective 1 -- Fraudulent Region Detection System}

\textbf{Purpose}

The purpose of this objective is to develop the initial detection functionality that identifies
where potentially fraudulent or duplicated regions exist within images.

The system will begin analyzing uploaded images and returning basic detection results
indicating suspicious areas that may have been manipulated through copy move
forgery.

\textbf{Detection System Technologies}

\begin{itemize}
    \item Python
    \item OpenCV
    \item NumPy
    \item Pillow
\end{itemize}

\textbf{Tasks}

\begin{itemize}
    \item Research image duplication detection methods
    \item Implement basic image analysis functionality
    \item Detect repeated or duplicated image regions
    \item Generate basic highlighted output for suspicious regions
    \item Connect detection system to backend API
    \item Return detection results to frontend interface
    \item Prepare frontend to display fraudulent region results
\end{itemize}

\subsection{Objective 2 -- Backend and Frontend Integration}

\textbf{Purpose}

Integrate the frontend image upload system with the backend detection functionality.

\textbf{Tasks}

\begin{itemize}
    \item Connect React frontend to FastAPI backend
    \item Send uploaded image data to backend API
    \item Process backend responses
    \item Display returned analysis results in frontend interface
    \item Improve error handling for invalid uploads
\end{itemize}

\subsection{Objective 3 -- Detection Workflow Update}

\begin{enumerate}

    \item Backend processes uploaded image
